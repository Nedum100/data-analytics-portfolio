📚 Book Data Analysis Using Python
📌 Project Overview

This project explores a dataset of books to analyze language distribution, ratings, pricing trends, and category patterns. The goal was to uncover patterns in publishing and reader preferences using exploratory data analysis (EDA).

🎯 Problem Statement

Book datasets often contain hidden insights about reader behavior, language dominance, and pricing trends. This analysis aims to:

Identify the most common book languages

Analyze rating distribution

Explore pricing patterns

Understand category trends

🛠 Tools & Libraries Used

Python

Pandas

Matplotlib

Seaborn

📊 Key Visualizations
Language Distribution

Rating Distribution

🔎 Key Insights

English was the dominant language across the dataset.

Certain categories have significantly higher average prices.

A small percentage of books drive the highest ratings.

💡 Business Value

Understanding book performance trends can help:

Publishers optimize pricing strategies

Identify high-performing categories

Target readers based on rating patterns

Guide marketing efforts
